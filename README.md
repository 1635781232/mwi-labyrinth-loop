# Milky Way Idle 测试服迷宫循环

一个只在 `test.milkywayidle.com` 生效的 Tampermonkey 用户脚本。它使用游戏现有的迷宫自动化，只负责进入、开始、等待、结束和补票。迷宫操作通过游戏现有 WebSocket 连接发送；侧栏导航仍使用页面点击。

## 安装

1. 安装 Tampermonkey。
2. 点击[安装脚本](https://raw.githubusercontent.com/1635781232/mwi-labyrinth-loop/main/mwi-labyrinth-loop.user.js)。
3. 打开测试服游戏页面，在右上角“迷宫循环 · 测试服”面板中点击“启用”。

脚本默认停用。Tampermonkey 会根据脚本中的 `@updateURL` 自动检查更新。

## 行为

- 启用脚本时若已有迷宫，会接管当前迷宫；页面刷新后也会继续接管。
- 当前处于其他活动时，迷宫交给游戏队列；脚本不会停止其他活动。
- 发送入场请求后会核对入场券或迷宫页面是否变化；若 15 秒内两者都未变化，会重试一次，仍无响应则暂停并提示检查连接。
- 任意两次游戏操作之间至少间隔 2 秒。
- 新迷宫发送一次“立即开始”对应的探索动作。脚本读取“自动化”栏的目标层数，与当前层数比较；到达目标且迷宫内“停止”消失后，发送退出请求。
- 入场券为 0 时打开设置，点击测试服的补充入口，并返回迷宫验证票数确实增加。
- 补充入口处于 3 小时冷却时保持等待。
- 离线回归出现“欢迎回来！”弹窗时，自动点击其中的“关闭”，然后继续迷宫流程。
- 退出请求等同于在游戏的两层确认框中最终确认。未知弹窗会暂停。
- 同一角色同时打开多个标签页时，使用角色级本地锁避免重复点击。

## 故障处理

状态面板显示当前阶段和最近操作。退出超过 60 秒仍未完成，或遇到未知弹窗时，脚本会暂停并显示“重试”按钮。

按住状态面板标题栏可拖动位置；位置会在刷新后保留。

遇到异常时可点击面板中的“复制详细日志”，复制脚本版本、当前状态和最近 100 条操作事件。日志不包含聊天内容或整页 DOM。

停用脚本会立即放弃对当前迷宫的托管，不会主动结束它。

# Milky Way Idle 测试服迷宫循环

一个只在 `test.milkywayidle.com` 生效的 Tampermonkey 用户脚本。它使用游戏现有的迷宫自动化，仅负责进入迷宫、首次开始、自动化停止后的结束，以及测试服入场券补充。

## 安装

1. 安装 Tampermonkey。
2. 点击[安装脚本](https://raw.githubusercontent.com/1635781232/mwi-labyrinth-loop/main/mwi-labyrinth-loop.user.js)。
3. 打开测试服游戏页面，在右上角“迷宫循环 · 测试服”面板中点击“启用”。

脚本默认停用。Tampermonkey 会根据脚本中的 `@updateURL` 自动检查更新。

## 行为

- 仅托管由脚本自己进入的迷宫。启用时若已有手动运行，脚本会等待玩家手动结束。
- 新迷宫只发出一次“立即开始/开始”。内置自动化停止后，脚本结束本次迷宫并进入下一轮。
- 入场券为 0 时打开设置，点击测试服的补充入口，并返回迷宫验证票数确实增加。
- 补充入口处于 3 小时冷却时保持等待。
- 已知的结束迷宫确认框会自动确认；补给或未知弹窗会暂停，等待玩家处理。
- 同一角色同时打开多个标签页时，使用浏览器 Web Locks 保证只有一个标签页执行。

## 故障处理

状态面板会显示当前阶段和最近五次操作。控件持续 20 秒无法识别、动作没有产生预期状态，或遇到未知弹窗时，脚本会暂停并显示“重试”按钮。

停用脚本会立即放弃对当前迷宫的托管，不会主动结束它。
